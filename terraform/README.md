# Terraform - Video Upload Database

> Este diretorio foi substituido pelo banco de dados compartilhado provisionado em `fiap-14soat-tc-fase4-iac-terraform`.
> A instancia RDS compartilhada reduz custos de ~$73/mes (6 instancias) para ~$15/mes (1 instancia).
>
> **Para criar o banco deste MS:** execute o workflow `deploy_infra.yaml` deste repositorio.
> Ele cria o banco `video_upload_db` na instancia RDS compartilhada via psql.
